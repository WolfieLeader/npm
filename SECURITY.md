# Security policy

## Supported versions

Only the latest major version of each package gets security fixes: `cipher-kit`, `compress-kit`, `generate-certs`,
`get-client-ip`, and `modern-cookies`.

## Report a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/WolfieLeader/npm/security/advisories/new).
Do not open a public issue, pull request, or discussion about it.

Include:

- The package and version.
- What an attacker can do, and the input or setup that triggers it.
- A proof of concept, if you have one.

The fix ships in a patch release, and the advisory is published with it. You are credited unless you ask not to be.
